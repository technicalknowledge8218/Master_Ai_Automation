## 1. OBJECTIVE & BENCHMARK METHODOLOGY

Before any new provider or model is wired into Master AI's production pipeline, it must pass a controlled, reproducible quality benchmark. 

This plan defines three representative reference projects spanning different visual media, aspect ratios, and narrative requirements. For each project, three distinct technical approaches are evaluated across nine standardized quality and financial metrics.

## 5. STANDARDIZED EVALUATION SCORECARD

Every approach across all three projects is scored across nine standardized dimensions:

```
┌────────────────────────────────────────────────────────────────────────┐
│ MASTER AI STANDARDIZED QUALITY SCORECARD (1 TO 10 SCALE)               │
├────────────────────────────────────────────────────────────────────────┤
│ 1. Visual Realism & Fidelity: Textures, lighting, photorealism         │
│ 2. Motion Quality: Fluidity, physics plausibility, lack of warping     │
│ 3. Character / Object Consistency: Morphology stability across cuts    │
│ 4. Scene Continuity: Lighting, color palette, and framing coherence    │
│ 5. Audio & Voice Quality: Intelligibility, prosody, mix clarity        │
│ 6. Editing Rhythm & Pacing: Cut timing, narrative tension, breathe     │
│ 7. Rendering Latency: Total wall-clock time from prompt to final MP4   │
│ 8. Unit Cost Efficiency: Financial spend per finished minute           │
│ 9. Commercial Viability: Clear copyright, royalty-free licensing      │
└────────────────────────────────────────────────────────────────────────┘
```

### Pre-Implementation Benchmark Execution Rules
1. **Local Baselines First:** Approaches A1, B1, and C1 must be implemented and tested locally first, establishing zero-cost benchmark targets on the host machine.
2. **Controlled Sandbox for Cloud Tests:** Cloud approaches (A2, B2, C2) will only be tested in Phase 7.2 using isolated single-shot test harnesses with strict pre-allocated credit budgets ($5.00 limit).
3. **No Unverified Claims:** Results from cloud providers without direct empirical test logs must remain categorized as `RESEARCH ESTIMATE`.
