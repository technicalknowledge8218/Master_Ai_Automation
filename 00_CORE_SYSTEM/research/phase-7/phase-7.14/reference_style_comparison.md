## 2. Key Takeaways for Master AI Production Engine

1. **Commit to a Single Visual Reality**:
   - If a film is a **2D Stylized Animation**, the background MUST be an illustrated 2D environment (e.g. vector living room, painted storefront, stylized cityscape).
   - If a film is a **Photorealistic Live-Action / Cinematic**, the footage MUST be real video and characters MUST be real actors or photorealistic AI video clips.
   - **Never mix a flat 2D cartoon cutout with photorealistic video.**

2. **Off-Center Dynamic Staging**:
   - Characters should move between rule-of-thirds anchors (left-aligned when speaking to the right; right-aligned for reaction shots; macro closeup on eyes/hands for dramatic tension).
   - Never freeze a character in the exact horizontal center across 3 consecutive shots.

3. **Grounded, Believable Narratives**:
   - Modern short-form viewers reject contrived, childish drama (e.g. fake bank alert misunderstandings).
   - Stories must feature genuine everyday Indian experiences, sharp tech ironies, relatable workplace conflicts, or smart observational comedy with logical cause-and-effect.
