## 1. Overview
The Capability Dashboard provides a single-pane-of-glass overview of the MASTER-AI ecosystem, showing:
- 30 Capability Domains & coverage status
- Active workspace skills and their test status
- Specialized local agent personas
- Host MCP servers
- Automated test run summaries
- Identified capability gaps and pending approvals
