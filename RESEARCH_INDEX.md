## 1. Research Protocol

All research conducted inside MASTER-AI must adhere to the 5-point verification standard:
1. **Primary Documentation**: Cite official vendor documentation, specification RFCs, or code repositories.
2. **Release & Version Verification**: Record tested software versions and documentation access dates.
3. **Reproducibility**: Provide concrete code snippets, shell commands, or benchmark scripts.
4. **Failure Analysis**: Document edge cases, failure modes, and known limitations.
5. **Actionable Output**: Distill research into a reusable template, skill, or rule.
