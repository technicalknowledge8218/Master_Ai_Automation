## 1. Executive Summary & Vision

**MASTER-AI** is a continuously improving, modular, globally reusable AI Knowledge, Skills, Agents, Automation, and Development Ecosystem. It is designed to solve a fundamental challenge in AI-assisted engineering: **context fragmentation, repetitive discovery, and inconsistent execution across projects**.

This workspace is not an ordinary software repository. It serves as the **central sovereign source of truth** across all domains of modern technology, AI development, and creative production:

- **AI Engineering & Machine Learning**: Foundations, LLMs, fine-tuning, inference, optimization, and computer vision.
- **RAG & Knowledge Architectures**: Hybrid search, vector stores, chunking, reranking, and private document extraction.
- **Autonomous Agents & Swarms**: Tool-calling agents, subagent delegation, swarm orchestration, and safety guardrails.
- **Full-Stack Software Development**: TypeScript, React, Node.js, Python, PostgreSQL, Android, and cloud deployments.
- **UI/UX & Modern Design Engineering**: World-class design tokens, component architecture, responsive layouts, and WCAG accessibility.
- **Model Context Protocol (MCP) & Tools**: Unified client-server tool integrations and sandboxed execution bridges.
- **Workflow Automation & Integrations**: n8n, webhooks, cron schedulers, and multi-service event orchestration.
- **Content Studio & Media Production**: Documentary scripting, viral short-form reels, AI video/audio generation, and editing pipelines.
- **Multi-Platform Social Media Engine**: Controlled multi-channel management (YouTube, Instagram, Telegram, X) with human approval gates.
- **Continuous Learning & Empirical Research**: Verified documentation, practical benchmarking, and zero-hallucination protocols.

Whenever starting any new project, an AI agent operating inside or outside this workspace can be instructed:
> *"First consult MASTER-AI. Load the relevant skills, rules, agents, references and development standards. Research any missing or outdated knowledge. Then plan and execute this project."*

## 2. Core Operating Principles

1. **Research Before Implementation**: Never guess, assume, or invent APIs. Always inspect official vendor documentation, verify version compatibility, and cite sources.
2. **Modern Coding Standards**: Write clean, modular, scalable, and secure code. No unnecessary dependencies, no hardcoded secrets, and no silent rewrites of working code.
3. **Continuous Empirical Learning**: When a new pattern, tool, or breakthrough is validated, it is captured, distilled into a skill, documented, and registered.
4. **Human-in-the-Loop Safety**: Critical actions—such as social publishing, destructive file operations, and global configuration deployments—require explicit human confirmation.
5. **Decoupled Deployment Architecture**: MASTER-AI remains the immutable source of truth. Deployments to Antigravity global configurations (`~/.gemini/config/`) run through a staged, validated, backup-enabled publishing pipeline.

## 5. How to Interact with MASTER-AI

### For AI Agents Operating in this Workspace
1. Read `AGENTS.md` and `MASTER_AI_RULEBOOK.md` immediately.
2. Adhere to the **Research Before Implementation** protocol.
3. Check `02_SKILLS` and `SKILL_CATALOG.md` before implementing complex multi-step workflows.
4. Record all newly validated patterns in `21_LEARNING_LAB` and update `LEARNING_PROGRESS.md`.

### For Deploying to Global Antigravity Configurations
Do not directly copy files into `~/.gemini/config/`. Always utilize the validated staging pipeline in `22_PUBLISH_AND_DEPLOY` and request explicit human approval before publishing.
